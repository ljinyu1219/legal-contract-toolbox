# 法务合同工具箱（Legal Contract Toolbox）

一个**纯前端、零后端、数据不出浏览器**的合同填报与审核辅助工具，覆盖合同填报 → 层级审核 → 模板生成全流程。打开一个 HTML 文件即可使用，无需安装、无需联网（首次加载后 mammoth.js 解析组件可离线缓存）。

> ⚠️ 免责声明：本工具仅供学习与内部效率参考，不构成法律意见。正式合同审查请以执业律师意见为准。

## 功能

### ① 商业信息填报助手

- 内置三类合同填报清单（均可通过「⚙ 字段设置」完全自定义）：
- 分步向导式填报，字段支持单选 / 多选勾选、显示条件联动；
- 填完自动运行**红线 / 预警校验引擎**（权利链、概括式授权、排他自营例外、转授权限定、分成计算基数、期限冲突、占位符残留等数十条规则），触碰红线需书面知悉后才能导出；
- 一键导出 Word 版《商业信息提供清单（申请表）》，草稿自动保存于浏览器本地。

### ② 对方模板参考

授权类合作中对方常先发来他们的合同模板。本工具支持：

- 上传对方合同（.docx / .txt）后**自动提取关键要素**：许可方式、转授权、金额、税率、授权区域、期限、违约金条款、渠道关键词等；
- 一键把可识别要素**带入填报表单**；
- 基于对方模板生成**我方口径的模板初稿**：独家/排他 → 非独家、允许转授权 → 不可转授权（书面同意除外）、管辖 → 甲方所在地法院等标准立场自动替换并**黄色高亮**，经法务逐条核对后可沉淀为我方模板。

### ③ 合同模板上传与初稿生成

- 上传己方合同模板后自动扫描占位符 / 残句 / 断链引用 / 空白附件；
- 按填报信息自动代入生成合同初稿（Word），未代入的占位符黄色高亮，附「须法务终审」提示。

### ④ 审核层级要点与意见生成

- 按四级审核流转（**业务初审 → 法务 → 财务 → 审批**）分口径核查清单：
  - 法务 22 项（权利链、权项逐项列明、许可方式、转授权传导、条款断链引用、违约责任对等性、附件一致性等）；
  - 财务 19 项（占位符扫描、计算基数、先票后款、发票品目、无保底应收管理等）；
- 逐项红 / 黄 / 绿判定 + 条款定位 + 修改建议，**任一红项结论强制为「不同意签署」**；
- 自动生成 Word 审核意见书（红项 / 黄项 / 通过项 / 补充材料四段式）与审批层一页纸摘要；
- 每层内置审核话术模板（退回话术、黄项沟通、否决理由等），支持自定义增删。

## 隐私与数据安全

- 所有填写内容、审核判定、上传的合同文本均**仅在浏览器本地处理与保存**（localStorage），不经过任何服务器；
- 各类草稿按合同类型独立保存，清除浏览器数据即彻底删除；
- 字段设置可导出 / 导入 JSON，便于团队内分发统一口径。

## 使用

```bash
# 方式一：直接打开
双击 index.html 即可

# 方式二：GitHub Pages
仓库 Settings → Pages → 选择 main 分支根目录

# 方式三：本地起服务
python -m http.server 8080
```

上传 .docx 需联网加载 mammoth.js（CDN）；.txt 模板完全离线可用。

## 定制

- 「⚙ 字段设置」面板可直接增删改任意合同类型的字段：名称、控件类型（文本 / 日期 / 单选 / 多选 / 下拉）、选项、必填、填写提示、显示条件（`字段ID=选项值`）；
- 章节与字段均可排序 / 删除 / 新增；
- 校验规则位于源码 `runChecks()` 函数，可按业务需要增改。

## 技术栈

原生 HTML / CSS / JavaScript 单文件实现，无框架、无构建；mammoth.js（CDN）用于浏览器内解析 .docx。
