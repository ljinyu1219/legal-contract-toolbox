⚖️ 法务合同工具箱

形象授权 · 图书出版 · 合同填报与层级审核 数据仅在本机浏览器内处理，不上传服务器

类型选择合同类型

不同合同类型使用不同的填报清单；切换类型会载入对应的表单（各类表单草稿独立保存）。

模板上传合同模板（可选）

若法务已在「③ 制式合同模板存档」入库，直接在上方从模板库选用即可，无需上传。也可在此临时上传 .docx/.txt 合同模板：自动扫描占位符/残句/空白附件；填完信息后可按模板生成合同初稿（已填项自动代入，未填项黄色高亮，供法务终审）。不选模板也可正常填报。
从模板库选用制式合同（法务已存档）
点击选择文件（.docx 或 .txt）

参考对方模板参考（快速形成我方模板）

授权类合作中对方常先发来他们的模板。上传后自动提取关键要素（许可方式/转授权/金额/税率/区域/期限/违约金/渠道），可一键带入填报；并可基于对方模板生成我方口径的模板初稿——非独家授权、不可转授权、甲方所在地法院等标准立场自动替换并标黄，经法务逐条核对后即可沉淀为我方模板。
点击选择对方模板（.docx 或 .txt）
用途：按引导逐项填写商业信息。填完自动校验红线与一致性，生成《商业信息提供清单（申请表）》；已上传模板的，可一键生成合同初稿。标 * 为必填。

校验结果风险自查

申请表预览
用途：按公司四级审核流转（业务初审 → 法务 → 财务 → 审批）逐项核查合同，标注红/黄/绿并定位条款，自动生成标准审核意见书与审核话术。任一红项存在时，结论强制为"不同意签署"。支持先上传合同文本（.docx / .doc / .pdf / .txt，或直接粘贴），边看原文边判定。

上传存入制式合同模板

由法务/管理员把各类制式合同模板（我方定稿版本）存档入库，供填报同事在「① 填报助手」直接选用。模板在本机浏览器内解析并保存（.docx 自动提取纯文字，不经任何服务器）；如需分发给其他同事，用下方「导出存档」生成 JSON 文件，对方在他们的页面里一键导入。
点击选择模板文件（.docx 或 .txt）

存档模板库

用途：对外提供合同文本（如供对方传阅、模板交流、案例分享）前，自动筛查并替换主体名称、统一社会信用代码、地址、联系方式、银行账户、金额价款、比例税率、合同编号等保密字段，一键生成脱敏版与原文对照表。全部处理在本机浏览器完成，不上传服务器。注意：品牌简称、内部项目代号等非格式化字段机器难以识别，请填入「自定义敏感词」；脱敏版对外发送前必须人工复核。
点击选择合同文件（.docx 或 .txt）
脱敏范围（勾选要替换的字段类型）
用途：对合同文本做机器预检，输出问题清单与 Word 检查报告。价款核对：大小写金额一致、小写缺大写、含税注明、0 元金额、大写「拾/壹拾」规范、比例超 100%；错别字与用词：签定/签订、订金/定金、抵消/抵销、帐/账、权力/权利等高频误写；标点格式：中英文标点混用、括号与引号不配对；条款引用：第 X 条空引用/断链、编号重复与跳号；日期：无效日期。规则来源于法务部审核要点沉淀，机器结果仅供辅助校对，最终以人工审校为准。
点击选择合同文件（.docx 或 .txt）
用途：公司制度归档库 + 制度问答。管理员模式（仅法务本人，密码保护）：上传制度文件、流程图与预设问答归档入库；问答：任何同事输入制度问题，工具按关键词在本机制度库内自动匹配答案并标注依据出处，全部数据不出浏览器。
